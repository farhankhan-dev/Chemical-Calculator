# Chemical-Calculator
A mobile application for solving core chemistry lab calculations — Normality, Molarity, Equivalent Weight, and Dilution — from a built-in chemical database. Enter a chemical name and get instant Molarity/Normality/Eq. Wt breakdowns, plus reverse calculators for required mass/volume and N₁V₁=N₂V₂ dilutions.
